# Família Prates — distribuição oficial

[Baixar a versão mais recente](https://github.com/Pr4Tes/familia-prates-updates/releases/latest)

Instale por cima, sem desinstalar nem limpar dados. Pacote, assinatura original e Room v2 preservados. O APK 1.3.0 é o já entregue com backup A/B opcional; não houve novo desenvolvimento desse recurso nesta publicação. Fontes privadas.

O atualizador confere manifesto assinado, compatibilidade, tamanho e SHA-256. Download e instalação dependem da ação/confirmação indicada no aplicativo. A primeira passagem de versões antigas sem atualizador é manual. Notas e arquivos oficiais estão nas releases.

Ensaios físicos entre aparelhos permanecem pendentes e foram dispensados pelo responsável nesta etapa. A verificação dos canais públicos por HTTPS e das assinaturas/pacotes é registrada separadamente.
